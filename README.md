## 面板服和游戏云 VPS 差在哪

代价是配置。面板服起步只有 1 核 2G，低于官方 4 核 8G 的最低要求。2 到 4 个朋友白天上线抓抓帕鲁、盖个小基地没问题，人再多或者建筑铺开了就会卡。它适合“先开起来玩玩”，不适合当长期主力服。

## 两个很容易踩的坑

**内存泄漏**。幻兽帕鲁有内存泄漏的老问题，跑久了占用一路往上涨，最后卡顿甚至崩服。雨云官方文档给了两个方案：8G 的机器额外开 8–12G SWAP 兜底；或者用脚本在内存占用超过 90% 时自动重启进程，回档大约 10 秒，玩家基本察觉不到。所以 4 核 8G 是能跑的底线，不是舒服的配置。长期开、建筑多，16G 更省心，省下的是你半夜被叫起来重启的功夫。

**主机平台连不上**。PS5 和 Xbox 不能像 PC 那样输入 IP 直连，只能从游戏的公共服务器列表里加入，也不支持 Tailscale 组网。想让主机朋友进来，只能把服务器设成半公开状态，靠服务器密码控制谁能进。如果你的队伍里有一半是主机玩家，这点在买之前就要想好。

## 下单之后怎么开

1. 买完进控制台，做 NAT 端口映射，把内网的 8211 端口映射到公网。
2. 用面板服的话直接点开启实例；用 VPS 的话，Windows 远程桌面跑一键部署脚本，Linux 用 SSH 跑对应脚本，看到成功提示就行，20 分钟内。
3. 游戏里选“加入多人游戏（专用服务器）”，在底部输入 `服务器IP:8211`，有密码就填密码。
4. 改规则的话，把默认模板 `DefaultPalWorldSettings.ini` 的内容复制到 `PalWorldSettings.ini` 才生效，直接改模板没用。常用项：`ServerPlayerMaxNum` 建议 4–8，`ExpRate` 休闲设 2.0–3.0，`PalCaptureRate` 设 1.5–2.0，`DeathPenalty` 可选 none。
5. 备份用快照最省事，手动的话打包 `Pal/Saved/` 目录就够了。
